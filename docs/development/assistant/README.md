# Agent 輔助資料

此目錄保存原根目錄的 Skill 來源、lockfile 及空 marker。移動只整理專案導覽，不安裝或啟用任何工具。

- `skills/using-superpowers/`：原 `.agents/skills/using-superpowers/`，內容保留。
- `skills-lock.json`：原根目錄 lockfile，來源及完整性欄位保留。
- `legacy-superpowers-marker.txt`：原 `SUPERPOWERSKILL` 空檔，保留於此供追溯。

這裡不是 Codex 的自動載入路徑。需使用特定 Skill 時，依實際工作環境的指令發現規則明確載入。專案不以複製 Skill 或 Agent 檔案取代測試與驗收。
